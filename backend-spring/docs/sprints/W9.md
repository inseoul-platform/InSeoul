## README 구성

### 1. 프로젝트 개요
- 서울 아파트 구매 전략 시뮬레이터 소개
- 스택 뱃지 (React, Spring Boot, FastAPI, MySQL, Docker)

### 2. 아키텍처 다이어그램 (ASCII)

```
Browser (Vite:5173)
       │ HTTP/SSE
       ▼
Spring Boot :8080  ──→  MySQL :3306
       │
       ├─→ FastAPI :8000 (RAG 챗봇)
       └─→ 국토부 API (서버사이드 프록시)
```

### 3. Quick Start (3가지 방법)

| 방법 | 명령 | 용도 |
|------|------|------|
| **개발 환경** | `make dev` | 로컬 개발 (MySQL Docker + 프로세스) |
| **Docker Compose** | `make docker-up` | 프로덕션 유사 환경 |
| **수동 기동** | 각 서비스 개별 명령 | 디버깅 |

### 4. 환경변수 표

| 변수 | 필수 | 기본값 | 설명 |
|------|:----:|--------|------|
| `VITE_API_BASE` | — | `http://localhost:8080` | 프론트 API 기준 URL |
| `JWT_SECRET` | ✅ (prod) | dev 기본값 포함 | JWT 서명 키 |
| `MOLIT_API_KEY` | — | — | 국토부 실거래가 API 키 |
| `OPENAI_API_KEY` | ✅ (챗봇) | — | FastAPI RAG 챗봇용 |
| `MYSQL_ROOT_PASSWORD` | — | `root` | Docker Compose MySQL |

### 5. API 엔드포인트 표
전체 21개 엔드포인트 도메인별 정리 (Auth, User, Districts, Loans, Strategies, Simulation, Chat, Health)

### 6. 인증 흐름
JWT 자체 로그인 + OAuth2 흐름 코드 블록

### 7. DB 스키마 개요
10개 테이블 역할 한 줄 설명

### 8. 프로젝트 구조 트리
```
InSeoul/
├── src/                    # React 프론트엔드
├── backend-spring/         # Spring Boot 백엔드
│   ├── src/main/java/com/inseoul/
│   └── src/main/resources/
├── backend/                # FastAPI 챗봇
```
