# W1 — 부트스트랩 & 인프라

> **상태**: ✅ 완료  
> **기간**: 2026-05-15

---

## 목표

Spring Boot 프로젝트 골격을 세우고, DB 연결 · Flyway · MyBatis · 공통 응답 · Swagger가 동작하는 베이스를 구축한다.

---

## 배경 / 왜 이 작업이 필요한가

프론트엔드가 국토부 API 키를 클라이언트에 노출하고 FastAPI를 직접 호출하는 구조였다. Spring Boot를 도입해 모든 요청을 단일 백엔드로 집중시키고, 외부 호출을 서버가 중계·캐싱하도록 일원화하는 것이 전체 프로젝트의 출발점이다.

---

## 기술 결정

| 항목 | 결정 | 이유 |
|------|------|------|
| ORM | MyBatis (JPA 아님) | 사용자 명시 요구사항 |
| DB 마이그레이션 | Flyway | 스키마 버전 관리 자동화 |
| API 문서 | springdoc-openapi 2.8.8 | Swagger UI + JWT Bearer 사전 등록 |
| 빌드 도구 | Gradle Kotlin DSL | 타입 안전 빌드 스크립트 |
| 공통 응답 | `ApiResponse<T>` envelope | `{success, data, error}` 일관성 |

---

## 산출물

| 파일 | 설명 |
|------|------|
| `build.gradle.kts` | 의존성: web, validation, mybatis, flyway, mysql, actuator, springdoc-openapi, lombok |
| `application.yml` | 공통 설정 (포트 8080, MyBatis mapper 경로, Swagger 경로) |
| `application-local.yml` | 로컬 DB 접속 정보 (localhost:3306/inseoul, root/root) |
| `application-prod.yml` | 운영 환경변수 참조 (`${DB_URL}` 등) |
| `db/migration/V1__init.sql` | 10개 테이블 DDL |
| `mappers/**/*.xml` | MyBatis mapper XML 디렉터리 골격 |
| `common/dto/ApiResponse.java` | 공통 응답 envelope |
| `common/exception/ErrorCode.java` | 오류 코드 enum |
| `common/exception/BaseException.java` | 비즈니스 예외 기반 클래스 |
| `common/exception/GlobalExceptionHandler.java` | `@RestControllerAdvice` 공통 예외 처리 |
| `config/OpenApiConfig.java` | Swagger UI + JWT Bearer 스키마 사전 등록 |
| `config/CorsConfig.java` | CORS 허용 (localhost:5173, 5500) |
| `health/HealthController.java` | `GET /api/health` — DB ping 포함 상태 반환 |

### V1 DB 스키마 (10개 테이블)

```
users               사용자 계정 (이메일/소셜 공통)
user_profiles       재무 프로필 (cash, monthlySavings, targetAmount, age, income)
user_sim_configs    시뮬레이션 설정 (LTV, 취득세율, 수익률 등)
oauth_accounts      소셜 계정 연결 (provider + provider_user_id)
refresh_tokens      JWT 갱신 토큰 (SHA-256 해시 저장)
districts           서울 25개 자치구 카탈로그
district_price_cache 국토부 가격 캐시 (24h TTL)
loan_products       정책 대출 상품 카탈로그
strategies          투자 전략
strategy_steps      전략별 단계
```

## 주요 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| Spring Boot 3.3.6 Initializr 거부 | 최소 지원 버전 3.5.0 | `bootVersion=3.5.0` 으로 변경 |
| MySQL 미설치 | 로컬에 MySQL 없음 | `docker run mysql:8.0` Docker 컨테이너 사용 |
