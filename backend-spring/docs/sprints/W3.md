# W3 — User / Profile / SimConfig

> **상태**: ✅ 완료  
> **기간**: W2 완료 후

---

## 목표

인증된 사용자의 재무 프로필과 시뮬레이션 설정을 CRUD. Bean Validation으로 입력 범위 검증. 회원 탈퇴 시 CASCADE 삭제.

---

## 도메인 설명

| 테이블 | 역할 | 관계 |
|--------|------|------|
| `user_profiles` | 재무 현황 (현금, 월저축, 목표금액, 나이, 소득) | users 1:1 |
| `user_sim_configs` | 시뮬레이션 파라미터 (LTV, 취득세율, 수익률 등) | users 1:1 |

---

## 산출물

| 파일 | 설명 |
|------|------|
| `user/domain/UserProfile.java` | userId, cash, monthlySavings, targetAmount, age, income |
| `user/domain/SimConfig.java` | userId + 5개 BigDecimal 파라미터 |
| `user/dto/UserProfileDto.java` | Bean Validation 어노테이션 포함 |
| `user/dto/SimConfigDto.java` | Bean Validation 어노테이션 포함 |
| `user/dto/UserMeResponse.java` | user + profile + simConfig 복합 응답 |
| `user/mapper/UserProfileMapper.java` + XML | findByUserId, update |
| `user/mapper/SimConfigMapper.java` + XML | findByUserId, update |
| `user/service/UserService.java` | getMe, updateProfile, updateSimConfig, deleteMe |
| `user/controller/UserController.java` | 4개 엔드포인트 |

---

## API

| Method | Path | 인증 | 설명 |
|--------|------|:----:|------|
| GET | /api/users/me | JWT | user + profile + simConfig 전체 조회 |
| PUT | /api/users/me/profile | JWT | 재무 프로필 수정 |
| PUT | /api/users/me/sim-config | JWT | 시뮬레이션 설정 수정 |
| DELETE | /api/users/me | JWT | 회원 탈퇴 (관련 데이터 CASCADE 삭제) |

### 요청/응답 예시

```json
// PUT /api/users/me/profile
{
  "cash": 8000,
  "monthlySavings": 250,
  "targetAmount": 80000,
  "age": 30,
  "income": 500
}

// Response
{
  "success": true,
  "data": { "cash": 8000, "monthlySavings": 250, "targetAmount": 80000, "age": 30, "income": 500 }
}
```

## 검증 규칙

| 필드 | 타입 | 최솟값 | 최댓값 | 단위 |
|------|------|--------|--------|------|
| cash | int | 0 | 100,000 | 만원 |
| monthlySavings | int | 0 | 5,000 | 만원 |
| targetAmount | int | 0 | 500,000 | 만원 |
| age | int | 18 | 80 | 세 |
| income | int | 0 | 5,000 | 만원/월 |
| savingsIncreaseRate | BigDecimal | 0.0 | 30.0 | % |
| investmentReturnRate | BigDecimal | -10.0 | 30.0 | % |
| apartmentAnnualRise | BigDecimal | 0.0 | 10.0 | % |
| ltvRatio | BigDecimal | 0.0 | 1.0 | 비율 |
| acquisitionTaxRate | BigDecimal | 0.0 | 0.1 | 비율 |

## 기본값 (신규 사용자 자동 생성)

`UserMapper.insertDefaultProfile`, `insertDefaultSimConfig` — 회원가입 시 INSERT IGNORE로 기본값 삽입.

| 프로필 | 기본값 |
|--------|--------|
| cash / monthlySavings / targetAmount | 0 |
| age | 30 |
| income | 500만원 |

| SimConfig | 기본값 |
|-----------|--------|
| savingsIncreaseRate | 5.00% |
| investmentReturnRate | 8.00% |
| apartmentAnnualRise | 3.00% |
| ltvRatio | 0.500 |
| acquisitionTaxRate | 0.0350 |
