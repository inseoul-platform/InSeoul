## 설계 원칙

| 원칙 | 구현 |
|------|------|
| 멱등성 | 각 서비스 시작 전 PID 파일 + `kill -0` 체크 → 이미 실행 중이면 재기동 생략 |
| 순차 기동 | `make dev` = `db → _wait-db → spring → _wait-spring → fastapi → frontend` |
| 헬스 대기 | `_wait-db`: mysqladmin ping (30회 폴링), `_wait-spring`: `/api/health` curl (60회 폴링) |
| ANSI 색상 | `$(shell printf '\033[...]')` — Make 평가 시점에 실제 이스케이프 시퀀스 생성 |
| 로그 분리 | Spring/FastAPI/Vite 각각 `/tmp/inseoul-*.log` |

## 타겟 목록

### 전체 스택 (4개)

| 타겟 | 설명 |
|------|------|
| `make dev` | MySQL → Spring → FastAPI → Vite 순차 기동 |
| `make stop` | Spring + FastAPI + Vite 전체 종료 |
| `make status` | 각 서비스 UP/DOWN 상태 + PID 표시 |
| `make logs` | Spring + FastAPI + Vite 로그 `tail -f` |

### MySQL (4개)

| 타겟 | 설명 |
|------|------|
| `make db` | Docker 컨테이너 생성/재시작 (idempotent) |
| `make db-stop` | 컨테이너 중지 |
| `make db-status` | 컨테이너 상태 표시 |
| `make db-shell` | MySQL CLI 접속 (`docker exec -it ... mysql`) |

### Spring Boot (4개)

| 타겟 | 설명 |
|------|------|
| `make spring` | 백그라운드 기동 (`SPRING_PROFILES_ACTIVE=local`) |
| `make spring-stop` | PID 기반 종료 |
| `make spring-log` | 로그 `tail -f` |
| `make spring-restart` | stop → 2s sleep → start |

### FastAPI (3개)

| 타겟 | 설명 |
|------|------|
| `make fastapi` | 백그라운드 기동 (최초 1회 `ingest.py` 자동 실행) |
| `make fastapi-stop` | PID 기반 종료 |
| `make fastapi-log` | 로그 `tail -f` |

### 프론트엔드 (2개)

| 타겟 | 설명 |
|------|------|
| `make frontend` | Vite 개발 서버 (`npm run dev`, 자동 `npm install`) |
| `make frontend-stop` | PID 기반 종료 |

### 빌드 (3개)

| 타겟 | 설명 |
|------|------|
| `make build` | 프론트엔드 + Spring JAR 전체 빌드 |
| `make build-spring` | `./gradlew bootJar -x test` |
| `make build-frontend` | `npm run build` → `dist/` |

### Docker Compose (3개)

| 타겟 | 설명 |
|------|------|
| `make docker-up` | `build` 후 `docker compose up -d` |
| `make docker-down` | `docker compose down` |
| `make docker-logs` | `docker compose logs -f` |

### DB 유틸 (2개)

| 타겟 | 설명 |
|------|------|
| `make migrate` | Flyway 마이그레이션 히스토리 조회 |
| `make seed` | districts/loans/strategies/strategy_steps 건수 확인 |

### 기타 (2개)

| 타겟 | 설명 |
|------|------|
| `make clean` | Gradle clean + dist/ 삭제 + PID/로그 파일 정리 |
| `make help` | 타겟 목록 컬러 출력 |

## 경로 변수

```makefile
ROOT_DIR    := $(shell pwd)                     # 프로젝트 루트
SPRING_DIR  := $(ROOT_DIR)/backend-spring       # Spring 디렉터리
FASTAPI_DIR := $(ROOT_DIR)/backend              # FastAPI 디렉터리

SPRING_PID  := /tmp/inseoul-spring.pid
FASTAPI_PID := /tmp/inseoul-fastapi.pid
VITE_PID    := /tmp/inseoul-vite.pid

SPRING_LOG  := /tmp/inseoul-spring.log
FASTAPI_LOG := /tmp/inseoul-fastapi.log
VITE_LOG    := /tmp/inseoul-vite.log
```

## 주요 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| ANSI 색상 미출력 | `BOLD := \033[1m` 리터럴이 `echo`에서 해석 안 됨 | `$(shell printf '\033[1m')` — Make 평가 시점에 실제 이스케이프 생성 |
| FastAPI 기동 시 벡터스토어 누락 | `vectorstore/` 디렉터리 없음 | `make fastapi`에서 `vectorstore` 미존재 시 자동 `python scripts/ingest.py` 실행 |
