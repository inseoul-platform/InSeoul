## 기술 결정

| 항목 | 결정 | 이유 |
|------|------|------|
| 시뮬레이션 위치 | 서버 + 클라 듀얼 모드 | 슬라이더 즉시 반응 보존, 서버는 PDF·공유링크 대비 |

| 스트레스 테스트 | 금리 +1%/+2%, 집값 +10%/+20% | 4가지 시나리오로 지연월수 산출 |

## GoldenCrossCalculator 주요 메서드

```java
// 골든크로스: 자산이 필요자본금을 처음 초과하는 월
GoldenCrossResult calcGoldenCross(cash, monthlySavings, targetAmount,
    investmentReturnRate, apartmentAnnualRise, ltvRatio, acquisitionTaxRate, savingsIncreaseRate)

// 스트레스: 금리/집값 시나리오별 지연 월수
StressResult calcInterestRateStress(..., double rateRisePct, double loanAmount)
StressResult calcPriceRiseStress(..., double priceRisePct)

// 차트: month별 자산/아파트가/필요자본금 포인트
List<ChartPoint> buildChartData(..., int horizonMonths)
```

입력 단위: 만 원 / 퍼센트(소수점 없음, e.g. `8.0` = 8%)  
MAX_MONTHS 안전망: 600개월 (50년) — 초과 시 null 반환
