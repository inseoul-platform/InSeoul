## Docker Compose 서비스 구성

| 서비스 | 이미지 | 포트 | 의존성 |
|--------|--------|------|--------|
| mysql | mysql:8.0 | 3306 | — |
| spring | ./backend-spring (Dockerfile.build) | 8080 | mysql (healthcheck) |
| fastapi | ./backend | 8000 | — |
| nginx | nginx:alpine | 80 | spring, fastapi |

### 주요 환경변수 (spring)

```yaml
SPRING_PROFILES_ACTIVE: prod
DB_URL: jdbc:mysql://mysql:3306/inseoul?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8
DB_USERNAME: root
DB_PASSWORD: ${MYSQL_ROOT_PASSWORD:-root}
JWT_SECRET: ${JWT_SECRET:-inseoul-prod-secret-change-me-256bits-long}
OAUTH2_REDIRECT_URI: ${FRONTEND_URL:-http://localhost}
MOLIT_API_KEY: ${MOLIT_API_KEY:-}
CHATBOT_URL: http://fastapi:8000  # 컨테이너 내부 통신
```

## Nginx 설정 핵심

```nginx
# Spring Boot API 프록시 (SSE 포함)
location /api/ {
    proxy_pass         http://spring;
    proxy_buffering    off;           # SSE: 버퍼링 비활성화
    proxy_cache        off;
    proxy_read_timeout 310s;          # 5분 SSE 타임아웃 + 여유
    proxy_set_header   Connection ''; # keep-alive
    chunked_transfer_encoding on;
}

# SPA 라우팅
location / {
    try_files $uri $uri/ /index.html;
}
```

OAuth2 `/oauth2/` 경로와 Swagger `/swagger-ui/`, `/v3/api-docs` 경로도 Spring으로 프록시.

## 실행 명령

```bash
# 개발 환경 (로컬 프로세스)
make dev

# 프로덕션 환경 (Docker Compose)
# 1. 프론트엔드 빌드 (dist/ 생성 — Nginx가 서빙)
make build-frontend

# 2. 환경변수 설정
export JWT_SECRET=your-256-bit-secret
export MYSQL_ROOT_PASSWORD=your-db-password
export MOLIT_API_KEY=your-molit-key        # optional
export OPENAI_API_KEY=your-openai-key      # FastAPI용

# 3. 전체 스택 기동
make docker-up    # = docker compose up -d (build 포함)

# 상태 확인
docker compose ps
curl http://localhost/api/health
```

## 주요 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| SSE 청크가 Nginx에서 끊김 | `proxy_buffering on` 기본값 | `proxy_buffering off` + `proxy_read_timeout 310s` 추가 |
| Spring 컨테이너가 DB 연결 실패 | mysql 컨테이너 초기화 전 Spring 기동 | `depends_on.mysql.condition: service_healthy` + mysqladmin ping healthcheck |
