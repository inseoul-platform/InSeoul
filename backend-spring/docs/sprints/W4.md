# W4 — District + 국토부 API 프록시

> **상태**: ✅ 완료 (국토부 실 키 검증 보류)  
> **기간**: W3 완료 후

---

## 목표

서울 25개 자치구 카탈로그 시드. 국토부 실거래가 XML API를 Spring이 프록시·캐싱. 새벽 스케줄러로 자동 갱신.

---

## 배경

기존 프론트엔드가 국토부 API를 클라이언트에서 직접 호출해 API 키가 브라우저에 노출되었다. Spring이 중계해 키를 서버에서만 관리하고, DB 캐시로 불필요한 외부 호출을 줄인다.

---

## 기술 결정

| 항목 | 결정 | 이유 |
|------|------|------|
| HTTP 클라이언트 | WebClient (WebFlux) | 논블로킹 외부 API 호출 |
| XML 파싱 | Java DOM Parser | Jackson XML 불필요한 복잡성 제거 |
| 캐시 저장소 | `district_price_cache` MySQL 테이블 | Redis 미도입 단계 (1만 회/일 초과 시 Redis 검토) |
| 캐시 TTL | 24시간 | `fetched_at` 컬럼 기준 |
| 갱신 전략 | Lazy (요청 시) + 새벽 일괄 (`@Scheduled`) | 조회 시 stale이면 즉시 갱신 + 새벽 전체 갱신 |
| Tier 분류 | VARCHAR(2) — S/A/B | V2 마이그레이션에서 TINYINT → VARCHAR 변경 |

## API

| Method | Path | Query | 설명 |
|--------|------|-------|------|
| GET | /api/districts | — | 25개구 목록 (code, region, lat, lng, tier) |
| GET | /api/districts/prices | `?refresh=false` | 전체 구 매매/전세 평균가 (24h 캐시) |
| GET | /api/districts/{code}/prices | — | 특정 구 가격 상세 |

### 응답 예시

```json
// GET /api/districts (일부)
{
  "success": true,
  "data": [
    { "code": "11680", "region": "강남구", "lat": 37.5172, "lng": 127.0473, "tierDefault": "S" },
    { "code": "11440", "region": "마포구", "lat": 37.5663, "lng": 126.9014, "tierDefault": "A" }
  ]
}

// GET /api/districts/prices (MOLIT_API_KEY 설정 시)
{
  "success": true,
  "data": [
    { "code": "11680", "region": "강남구", "tradeAvg": 185000, "rentAvg": 85000, "fetchedAt": "2026-05-15T04:00:00" }
  ]
}
```

## 25개구 Tier 분류

| Tier | 해당 구 |
|------|---------|
| S (최고가) | 종로구, 중구, 용산구, 서초구, 강남구, 송파구 |
| A (일반) | 성동구, 광진구, 동대문구, 성북구, 서대문구, 마포구, 양천구, 강서구, 영등포구, 동작구, 강동구 |
| B (접근가능) | 중랑구, 강북구, 도봉구, 노원구, 은평구, 구로구, 금천구, 관악구 |

## 국토부 API 호출 방식

```
매매: GET https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade
       ?serviceKey={key}&LAWD_CD={code}&DEAL_YMD={yyyyMM}&numOfRows=2000

전세: GET https://apis.data.go.kr/1613000/RTMSDataSvcAptRent/getRTMSDataSvcAptRent
       (같은 파라미터)

처리: 최근 3개월 × 거래 건수 전체 평균 → 만원 단위
```

## 주요 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| V2 마이그레이션 실패 | `tier_default TINYINT`에 'S' 문자 삽입 불가 | V2에 `ALTER TABLE ... MODIFY COLUMN tier_default VARCHAR(2)` 선행 |
| Flyway 실패 후 재시도 불가 | `flyway_schema_history`에 V2 failed 기록 | `DELETE FROM flyway_schema_history WHERE version='2'` 후 재기동 |
