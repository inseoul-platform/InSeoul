# W6 — Chat SSE 중계

> **상태**: ✅ 완료  
> **기간**: W5 완료 후

---

## 목표

Spring `/api/chat` 엔드포인트가 FastAPI SSE 스트림을 그대로 클라이언트에 패스스루. 5분 타임아웃, FastAPI 장애 시 에러 이벤트 graceful 처리.

---

## 배경

기존 프론트엔드가 `http://127.0.0.1:8000/chat`를 직접 SSE 구독. API 키 노출 + CORS 우회 문제. Spring이 중계해 FastAPI 엔드포인트를 외부에 숨기고, 향후 인증·로깅 적용 가능하도록 일원화.

---

## 기술 결정

| 항목 | 결정 | 이유 |
|------|------|------|
| Tomcat SSE | `SseEmitter(300_000L)` | WebFlux 전면 전환 없이 Tomcat에서 SSE |
| 비동기 실행 | `Executors.newVirtualThreadPerTaskExecutor()` | Virtual Threads (Java 21), 스레드풀 오버헤드 없음 |
| FastAPI 호출 | `WebClient` + `bodyToFlux(String.class)` | 청크 단위 수신, 비동기 논블로킹 |
| SSE 파싱 | FastAPI raw `data: {...}\n\n` 그대로 패스스루 | 파싱 없이 직통 → 클라이언트가 직접 파싱 |
| 에러 처리 | `onErrorReturn` + `doOnError` → 에러 이벤트 emit | FastAPI 5xx/타임아웃 시 graceful 종료 |
| chatbotUrl | `@Value("${chatbot.url:http://127.0.0.1:8000}")` | 환경변수 `CHATBOT_URL`로 주입, 기본값 로컬 |

## API

| Method | Path | Body | Response | 설명 |
|--------|------|------|----------|------|
| POST | /api/chat | `ChatRequest` | `text/event-stream` | FastAPI SSE 패스스루 |

### 요청 예시

```json
{
  "message": "강남구 아파트 매매 시장 어때?",
  "history": [
    {"role": "user", "content": "안녕"},
    {"role": "assistant", "content": "안녕하세요!"}
  ],
  "context": {
    "page": "DashboardScreen",
    "userProfile": { "cash": 8000, "targetAmount": 80000 },
    "simConfig": { "ltvRatio": 0.5 }
  }
}
```

### SSE 응답 스트림

```
data: {"type":"token","content":"강남구"}

data: {"type":"token","content":" 아파트"}

data: {"type":"done"}
```

### 에러 이벤트 (FastAPI 장애 시)

```
data: {"type":"error","message":"챗봇 서버에 연결할 수 없습니다."}
```

## SSE 흐름

```
클라이언트 POST /api/chat
  → ChatController: SseEmitter 생성 (5분 타임아웃)
  → VirtualThread: ChatRelayService.relay(req) 호출
      → WebClient.post(chatbotUrl/chat)
          → bodyToFlux(String) — 청크 수신
              → "data: {...}" 형식이면 payload 추출
              → SseEmitter.event().data(payload) 전송
          → doOnComplete → emitter.complete()
          → doOnError → 에러 이벤트 emit → emitter.complete()
클라이언트 수신 종료
```

---

## 응답 헤더

| 헤더 | 값 | 용도 |
|------|----|------|
| `Content-Type` | `text/event-stream` | SSE 표준 |
| `X-Accel-Buffering` | `no` | Nginx 버퍼링 비활성화 |
| `Cache-Control` | `no-cache` | 중간 캐시 방지 |

> Nginx `proxy_buffering off` + `proxy_read_timeout 310s` 설정 필요 (W8 nginx.conf에서 처리)
