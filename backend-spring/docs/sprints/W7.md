# W7 — 프론트 API 연동

> **상태**: ✅ 완료  
> **기간**: W6 완료 후

---

## 목표

프론트엔드가 국토부 API · FastAPI를 직접 호출하던 것을 Spring Boot 경유로 전환. JWT 인터셉터가 포함된 공통 apiClient 구축. 로그인 화면 및 OAuth2 콜백 핸들러 구현.

---

## 배경

W1~W6에서 Spring 백엔드가 완성됐지만, 프론트는 아직:
- `api.js`: 국토부 XML API를 직접 호출 (API 키 노출)
- `chatbotService.js`: `http://127.0.0.1:8000/chat`을 직접 SSE 구독
- 로그인/인증 UI 없음, 사용자 데이터 localStorage만 사용

이 스프린트에서 모든 외부 직접 호출을 제거하고 Spring으로 일원화.

## apiClient.js 주요 기능

```javascript
// baseURL: import.meta.env.VITE_API_BASE ?? 'http://localhost:8080'
// timeout: 15,000ms

// 요청 인터셉터: localStorage('inseoul-auth')에서 accessToken 읽어 Bearer 헤더 첨부
apiClient.interceptors.request.use(config => {
    const tokens = getTokens();
    if (tokens?.accessToken) config.headers.Authorization = `Bearer ${tokens.accessToken}`;
    return config;
});

// 응답 인터셉터: 401 수신 → refreshToken으로 재발급 → 원래 요청 재시도
// 동시 다중 401: waiters 큐로 한 번만 갱신
// 갱신 실패: clearTokens() + window.dispatchEvent(new Event('auth:logout'))
```

export: `getTokens()`, `setTokens(accessToken, refreshToken)`, `clearTokens()`, default `apiClient`

## useAppStore.js 추가 사항

```javascript
// 추가된 인증 상태
authUser: null,

// 추가된 액션
setAuth(user, accessToken, refreshToken),  // 토큰 저장 + authUser 설정
clearAuth(),                                // 토큰 제거 + authUser 초기화
isLoggedIn(),                               // accessToken 존재 여부
hydrateFromServer(),                        // GET /api/users/me → 프로필/시뮬레이션 설정 동기화
pushProfile(profile),                       // PUT /api/users/me/profile
pushSimConfig(config),                      // PUT /api/users/me/sim-config
```

`authUser`는 `partialize`에 포함되어 localStorage에 지속.

## LoginScreen.jsx 주요 기능

- 이메일/패스워드 로그인 + 회원가입 토글
- `POST /api/auth/login` → `setAuth()` → 홈 이동
- `POST /api/auth/signup` → 동일 흐름
- Kakao OAuth2 버튼: `window.location.href = {API_BASE}/oauth2/authorization/kakao`
- Google OAuth2 버튼: `window.location.href = {API_BASE}/oauth2/authorization/google`
- URL fragment 콜백 핸들러 (`useEffect`):
  ```
  URL: /#accessToken=eyJ...&refreshToken=eyJ...
  → URLSearchParams(hash.slice(1)) 파싱
  → setTokens() 저장
  → history.replaceState(null, '', pathname)  // URL 정리
  → GET /api/users/me → setAuth() → navigate('/')
  ```
- "비로그인으로 사용" 링크 (인증 없이 앱 접근)

## api.js 변경 (국토부 → Spring)

```javascript
// 이전: 국토부 XML API 직접 호출 + localStorage 캐시
async function loadSeoulAptPrices() {
  // ... MOLIT API 직접 호출 코드 ...
}

// 이후: Spring /api/districts/prices 호출
import apiClient from './apiClient';
async function loadSeoulAptPrices() {
  const { data: res } = await apiClient.get('/api/districts/prices');
  return res.data;
}
```

## chatbotService.js 변경 (FastAPI → Spring)

```javascript
// 이전
const resp = await fetch('http://127.0.0.1:8000/chat', { ... });

// 이후
const API_BASE = import.meta.env.VITE_API_BASE ?? 'http://localhost:8080';
const tokens = getTokens();
const resp = await fetch(`${API_BASE}/api/chat`, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        ...(tokens?.accessToken && { Authorization: `Bearer ${tokens.accessToken}` }),
    },
    body: JSON.stringify(payload),
});
```
