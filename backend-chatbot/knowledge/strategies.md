# 서울 아파트 구매 전략

## 전략 개요

InSeoul에서 제공하는 주요 구매 전략은 릴레이 전략과 다운사이즈 전략이다.
각 전략은 사용자의 현재 자산 규모, 목표 지역, 리스크 허용 범위에 따라 선택한다.

## 릴레이 전략 (Relay Strategy)

### 개념

낮은 가격의 아파트를 먼저 구매한 뒤, 시세차익으로 더 비싼 목표 아파트로 갈아타는 단계적 전략이다.

### 4단계 실행 방법

**1단계: 자금 확보**
- 현재 보유 현금 + 골든크로스 시점까지 저축 누적
- 1차 목표 지역 선정: 현재 자본금으로 진입 가능한 서울 외곽 구 (노원, 강북, 도봉 등)
- 전세 거주 중이라면 보증금을 활용한 레버리지 가능

**2단계: 임장 (현장 조사)**
- 목표 지역 직접 방문, 교통·학교·상권 확인
- 매매가 대비 전세가 비율(전세가율) 확인 (전세가율 높으면 실수요 강함)
- 재개발·재건축 정비사업 진행 현황 확인
- 인근 신축 분양가와 비교

**3단계: 금융 상품 선택**
- 보금자리론 또는 디딤돌대출 적격 여부 확인
- LTV, DSR 한도 내 최적 대출 구조 설계
- 중도상환수수료 없는 상품 우선 선택

**4단계: 계약 및 관리**
- 매매 계약, 잔금 처리
- 실거주 또는 전세 운용으로 현금 흐름 관리
- 2차 목표 지역 상승 시 매각 후 갈아타기 실행

### 릴레이 전략 장점
- 초기 자본금이 적어도 서울 시장 진입 가능
- 부동산 상승기에 시세차익으로 다음 단계 가속
- 실거주하며 자산 형성 가능

### 릴레이 전략 단점
- 이사 비용, 취득세 중복 발생
- 목표 지역 가격 상승 속도가 빠르면 갈아타기 어려움
- 전세 만기, 매매 타이밍 조율 필요

## 다운사이즈 전략 (Downsize Strategy)

### 개념

목표 아파트의 크기나 위치를 조정해 필요 자본금을 낮추고, 골든크로스를 빠르게 달성하는 전략이다.

### 실행 방법

**방법 1: 평형 축소**
- 34평 → 24평으로 변경 시 약 20~30% 가격 절감
- 1인 또는 2인 가구라면 소형 평형으로 충분
- 소형은 전세 수요도 높아 환금성 양호

**방법 2: 지역 하향**
- 강남 → 동작 → 관악 순으로 목표 구 조정
- 동일 예산으로 더 넓은 평형 확보 가능
- 교통망 개선 예정 지역(GTX, 신안산선 등) 우선 고려

**방법 3: 신축 → 구축으로 변경**
- 동일 지역 구축 아파트는 신축 대비 20~40% 저렴
- 재건축 가능 연한(30년 이상) 구축은 장기 호재 기대 가능
- 구축 선택 시 누수, 주차, 커뮤니티 시설 확인 필수

### 다운사이즈 장점
- 골든크로스 달성 시점 크게 단축
- 대출 부담 감소, 월 이자 절감
- 생활 수준 유지하면서 자산 형성

### 다운사이즈 단점
- 최종 목표 아파트 입주 시점 지연 가능
- 처음부터 원하는 곳이 아닐 수 있어 심리적 타협 필요

## 징검다리 전략 (Stepping Stone Strategy)

릴레이와 다운사이즈를 결합한 혼합 전략:

1. 소형 구축 아파트(저가) 구매 → 실거주 또는 임대
2. 3~5년 후 시세차익 + 저축 누적
3. 중형 또는 목표 지역 이동

## 전략 비교표

| 항목 | 릴레이 | 다운사이즈 | 징검다리 |
|------|--------|-----------|---------|
| 초기 자본 | 중 | 낮음 | 낮음 |
| 이사 횟수 | 2회 이상 | 1~2회 | 2회 이상 |
| 취득세 부담 | 중복 발생 | 1~2회 | 중복 발생 |
| 목표 달성 속도 | 중간 | 빠름 | 중간~빠름 |
| 최종 주거 만족도 | 높음 | 타협 필요 | 중간 |
| 적합 대상 | 상승기 투자 의향자 | 빠른 자산 형성 원하는 경우 | 장기 계획 수립자 |

## InSeoul에서 전략 선택 가이드

**릴레이 전략 추천 상황:**
- 현재 골든크로스 시점이 10년 이상 남음
- 목표 아파트가 강남·서초 등 고가 지역
- 부동산 상승장 진입 타이밍

**다운사이즈 추천 상황:**
- 골든크로스 시점을 5년 이내로 단축하고 싶을 때
- 대출 상환 부담을 최소화하고 싶을 때
- 시뮬레이션에서 투자 수익률 조정이 효과 없을 때

**전략 전환 시점:**
- 1차 아파트 전세가율이 80% 이상 → 매도 적기
- 목표 지역 재건축 착공 발표 → 빠른 갈아타기 필요
- 금리 급등 시 → 대출 비중 줄이는 다운사이즈로 전환
